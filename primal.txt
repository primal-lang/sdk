For the past few years, I’ve been building Primal — a minimalist, declarative programming language designed to make core programming concepts simple and accessible.

💡 Why build another language?
Modern languages are powerful, but they often come with layers of complex syntax, heavy configuration, and cognitive overhead. Primal strips away that complexity to focus on what truly matters: declarative problem-solving.

✨ Functional Simplicity:
Inspired by Lambda Calculus — every value is immutable, functions are first-class, and everything is an expression.

🎓 Built for Learning:
Designed with an education-first mindset. Designed to introduce programming concepts with a small syntax and minimal boilerplate.

🛠️ Key Highlights:
• 300+ standard library functions (math, collections, time, strings, I/O, encoding, and more)
• Interactive REPL with persistent history & live evaluation
• Built-in test runner
• Cross-platform (Linux, macOS, and Windows)
• 100% Free & Open Source

🚀 In the latest release:
• Let expressions
• Anonymous functions (lambdas)
• 70+ new built-in functions
• Self-updating CLI
